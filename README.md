## Dataset
UCI Student Performance Dataset

Source:
https://archive.ics.uci.edu/dataset/320/student+performance

We will analyze the student-por.csv file, which contains 649 student records and variables related to academic performance, study habits, attendance, family background, and educational support.

## Project Goal
This project examines how study habits, school attendance, and educational support are related to students' final academic performance.
